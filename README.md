# Meu Projeto de Site em HTML5

Este é um projeto simples de um site em HTML5. Ele demonstra o uso básico de várias tags HTML5 comuns.

## Estrutura do Projeto

O projeto consiste nos seguintes arquivos:

- `index.html`: O arquivo principal contendo a estrutura do site.
- `style.css`: O arquivo de estilos CSS.

## Tags HTML5 Utilizadas

### Estrutura Básica

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Site em HTML5</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
</body>
</html>
```
# Tags Semânticas

- `<header>`: Cabeçalho da página.
- `<nav>`: Navegação principal.
- `<main>`: Conteúdo principal.
- `<section>`: Seção do conteúdo.
- `<article>`: Artigo independente.
- `<aside>`: Conteúdo secundário.
- `<footer>`: Rodapé da página.

# Outras Tags Comuns

- `<div>`: Divisão genérica de conteúdo.
- `<span>`: Elemento em linha genérico.
- `<h1> a <h6>`: Títulos de diferentes níveis.
- `<p>`: Parágrafo.
- `<a>`: Link.
- `<img>`: Imagem.
- `<ul>`, `<ol>`, `<li>`: Listas não ordenadas, ordenadas e itens de lista.
- `<form>`: Formulário.
- `<input>`: Campo de entrada.
- `<button>`: Botão.
- `<table>`, `<tr>`, `<td>`, `<th>`: Tabela, linha de tabela, célula de dados e célula de cabeçalho.

# Como Executar

1. Clone o repositório: `git clone https://github.com/seu-usuario/meu-projeto-html5.git`
2. Navegue até o diretório do projeto: `cd meu-projeto-html5`
3. Abra o arquivo `index.html` em um navegador web.
